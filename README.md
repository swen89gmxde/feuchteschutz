## Umfang, Lüftungskonzept und Förderung

Der kurze dokumentierte Blick auf Lüftung/Feuchteschutz bei jedem Fenstertausch ist eine Empfehlung für Sichtwerk, keine Behauptung einer allgemeinen gesetzlichen Formularpflicht. DIN 1946-6:2019-12, Abschnitt 4.1, nennt den Austausch von mehr als einem Drittel der vorhandenen Fenster einer Nutzungseinheit als Beispiel einer lüftungstechnisch relevanten Änderung. Keine abschließende Prüfgrenze oder Haftungsbefreiung für Kleinmaßnahmen. Frühere Austauschschritte, weitere Abdichtungen, Feuchteprobleme, kalte Anschlüsse und Wechselwirkungen mit Ablufttechnik / Feuerstätten mitbetrachten.

DIN 4108-7:2026-04 enthält einen eigenen Abschnitt zum Luftdichtheitskonzept; dieses ist von der Lüftungsplanung zu unterscheiden. Die technischen FAQ BEG EM, Version 7.0 (06/2026), Nr. 2.03, S. 12–13, verlangen bei geförderten Sanierungsmaßnahmen mit erhöhter Luftdichtheit einen Lüftungskonzept-Nachweis zur Prüfung notwendiger Maßnahmen, ohne dortige Drittel-Ausnahme. Antrag / Förderzusage und Energieeffizienz-Experten berücksichtigen. Diese Anforderung bestand schon in früheren Förderunterlagen.

Bei größerem/unklarem Umfang oder ausgewähltem BEG-Förderfall ist keine pauschale Kleinfall-Einschätzung möglich: geeignete Planung zuordnen oder offenen Klärungsbedarf konkret dokumentieren. Das Formular ersetzt kein Konzept und trifft keine automatische technische Entscheidung.
